# 玩家指南

[English](player-guide.md) · [简体中文](player-guide.zh-CN.md) · 繁體中文

本指南整理玩家日常常用的經濟指令與操作方式。AceEconomy v2 採「主指令加子動作」結構（例如查詢餘額為 `/money balance`）。指令格式中，`<...>` 代表必填參數，`[...]` 代表選填參數；實際執行時請替換為具體數值，無須輸入外層括號。若省略 `[currency]`，系統自動採用伺服器預設貨幣。

## 開始前

1. **指令格式：** v2 所有指令均須帶有具體子指令（如 `/money balance`、`/pay send`），不再支援舊版裸指令縮寫。
2. **貨幣 ID：** 貨幣 ID 為英數字代碼（例如 `dollar`、`token`），可能與遊戲內顯示名稱或符號不同；若不確定伺服器啟用的貨幣 ID，請向管理員確認。

## 我想查詢餘額

### 查詢自身餘額

執行以下指令查看預設貨幣餘額：

```text
/money balance
```

若需查詢特定貨幣，請於玩家名稱後附加貨幣 ID：

```text
/money balance <player> <currency>
```

此操作需要 `aceeconomy.command.money` 權限。若未顯示金額，請參閱[常見輸入問題](#常見輸入問題)。

### 查詢其他玩家餘額

輸入目標玩家名稱，可選填貨幣 ID：

```text
/money balance <player> [currency]
```

例如查詢 Alex 的 `token` 餘額：

```text
/money balance Alex token
```

## 我想付款給其他玩家

使用轉帳指令付款給其他線上玩家：

```text
/pay send <player> <amount> [currency]
```

範例（以預設貨幣轉帳 250 元給 Alex）：

```text
/pay send Alex 250
```

指定貨幣轉帳（轉帳 10 枚 token 給 Alex）：

```text
/pay send Alex 10 token
```

`/pay` 僅限玩家執行，需要 `aceeconomy.command.pay` 權限。轉帳金額必須大於 0，且不得超出該貨幣設定的小數位數上限。交易成功後雙方均會收到系統通知。

## 我想把錢變成可以攜帶的物品

### 提領銀行支票

執行提領指令將帳戶餘額轉換為實體支票物品。執行前請確認背包至少有一格空位：

```text
/withdraw cash <amount> [currency]
```

範例：

```text
/withdraw cash 100
```

系統自餘額扣除指定金額後發放實體支票。此指令僅限玩家執行，需要 `aceeconomy.command.withdraw` 權限。

### 兌回銀行支票

兌回支票有兩種方式，效果相同且具備嚴格的防重入機制（伺服器記錄已兌換序號，每張支票僅限入帳一次）：

1. **透過銀行選單：** 輸入 `/bank open` 開啟面板，手持支票點擊存入按鈕。
2. **手持直接兌換：** 將支票拿在手上，點擊滑鼠右鍵。

若兌回過程發生異常：
- **存入被拒絕：** 物品無效、已被兌換或貨幣不存在時，支票會保留在背包內。請勿重複嘗試，聯絡管理員確認。
- **扣除延遲或保留：** 若款項已入帳但物品未能自動清除，伺服器會記錄交易 ID 與入帳明細。請保留物品並聯絡管理員核對。

## 我想查看富豪排行榜

想知道誰最有錢，打：

```text
/baltop top [currency]
```

不填貨幣就用伺服器設定的預設貨幣。想看特定貨幣這樣打：

```text
/baltop top token
```

這個指令需要 `aceeconomy.command.baltop`，會列出所選貨幣的排名、玩家名稱與餘額。

## 我想使用銀行面板

執行以下指令開啟銀行儀表板選單：

```text
/bank open
```

此指令僅限玩家執行，需要 `aceeconomy.command.bank` 權限。若伺服器在玩家開啟介面期間重載了版面設定，選單會自動依新版面重建並在原地重整。

- **Java 版客戶端：** 呈現自訂箱子 GUI，提供帳戶資訊、資產明細、歷史紀錄及支票存提按鈕。
- **基岩版客戶端（Geyser + Floodgate）：** 呈現原生表單，顯示餘額並提供存入、提領與關閉選項。提領時需輸入金額與幣別，並經二次確認後才執行交易。
兩種客戶端共用同一套底層經濟邏輯，具備完全相同的餘額驗證與防偽規則。

## 我想使用多種貨幣

想用預設貨幣以外的餘額，就在指令後面加上貨幣 ID。所有標示 `[currency]` 的指令都接受伺服器設定中的貨幣 ID。預設設定包含 `dollar` 與 `token`，伺服器也可以另外定義更多貨幣。

平常的經濟就省略貨幣 ID，活動的獨立餘額就把 ID 加上去：

```text
/money balance <player> token
/pay send Alex 10 token
/withdraw cash 5 token
/baltop top token
```

找貨幣 ID 時大小寫與前後空白不會對應到另一個貨幣，但金額仍要符合該貨幣設定的小數位數。`scale: 0` 的貨幣只能輸入整數；`scale: 2` 的貨幣最多可輸入兩位小數。被提示金額無效就先看[常見輸入問題](#常見輸入問題)。

## 我想了解管理員造成的餘額變化

管理員可以發放、扣除或直接設定玩家餘額。這些操作影響到你時，AceEconomy 可以顯示包含金額與貨幣的玩家通知。想確認結果就查一次餘額：

```text
/money balance
```

如果你預期會收到獎勵或修正，卻看不懂餘額變化，請向伺服器管理員確認交易背景。管理指令語法與權限請參考[指令與權限](commands.zh-TW.md)。

## 常見輸入問題

### 指令提示金額無效

先確認三件事：輸入的是有效數字、金額大於 0、小數位數沒有超過該貨幣的設定。過大的金額也會被拒絕。如果貨幣使用 `scale: 2`，可以先用 `10` 或 `10.50` 這類小額測試。

### 找不到貨幣

請輸入伺服器設定的貨幣 ID，不要輸入顯示名稱或符號。支援補字的情況下，輸入指令時會出現貨幣建議；如果仍然被拒絕，請向管理員確認目前啟用的貨幣。

### 找不到玩家

請檢查拼字，並使用伺服器能辨識的玩家名稱。執行 `/pay send` 時，也請確認你是以玩家身分輸入，而且不是付款給自己。

### 我沒有權限

請伺服器管理員確認該指令的權限：

| 指令 | 權限 |
| --- | --- |
| `/money` | `aceeconomy.command.money` |
| `/pay` | `aceeconomy.command.pay` |
| `/withdraw` | `aceeconomy.command.withdraw` |
| `/baltop` | `aceeconomy.command.baltop` |
| `/bank` | `aceeconomy.command.bank` |

### 銀行支票沒有出現在背包

先檢查背包是否已滿；沒有空位時無法取得銀行支票。如果指令顯示經濟系統錯誤，請先確認金額與可用餘額，問題持續時再請管理員協助。
