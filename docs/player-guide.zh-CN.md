# 玩家指南

[English](player-guide.md) · 简体中文 · [繁體中文](player-guide.zh-TW.md)

本指南整理玩家日常常用的经济指令与操作方式。AceEconomy v2 采用「主指令加子动作」结构（例如查询余额为 `/money balance`）。指令格式中，`<...>` 代表必填参数，`[...]` 代表选填参数；实际执行时请替换为具体数值，无须输入外层括号。若省略 `[currency]`，系统自动采用服务器默认货币。

## 开始前

1. **指令格式：** v2 所有指令均须带有具体子指令（如 `/money balance`、`/pay send`），不再支持旧版裸指令缩写。
2. **货币 ID：** 货币 ID 为英数字代码（例如 `dollar`、`token`），可能与游戏内显示名称或符号不同；若不确定服务器启用的货币 ID，请向管理员确认。

## 我想查询余额

### 查询自身余额

执行以下指令查看默认货币余额：

```text
/money balance
```

若需查询特定货币，请于玩家名称后附加货币 ID：

```text
/money balance <player> <currency>
```

此操作需要 `aceeconomy.command.money` 权限。若未显示金额，请参阅[常见输入问题](#常见输入问题)。

### 查询其他玩家余额

输入目标玩家名称，可选填货币 ID：

```text
/money balance <player> [currency]
```

例如查询 Alex 的 `token` 余额：

```text
/money balance Alex token
```

## 我想付款给其他玩家

使用转账指令付款给其他在线玩家：

```text
/pay send <player> <amount> [currency]
```

范例（以默认货币转账 250 元给 Alex）：

```text
/pay send Alex 250
```

指定货币转账（转账 10 枚 token 给 Alex）：

```text
/pay send Alex 10 token
```

`/pay` 仅限玩家执行，需要 `aceeconomy.command.pay` 权限。转账金额必须大于 0，且不得超出该货币设置的小数位数上限。交易成功后双方均会收到系统通知。

## 我想把钱变成可以携带的物品

### 提取银行支票

执行提领指令将账户余额转换为实体支票物品。执行前请确认背包至少有一格空位：

```text
/withdraw cash <amount> [currency]
```

范例：

```text
/withdraw cash 100
```

系统自余额扣除指定金额后发放实体支票。此指令仅限玩家执行，需要 `aceeconomy.command.withdraw` 权限。

### 兑换银行支票

兑回支票有两种方式，效果相同且具备严格的防重入机制（服务器记录已兑换序号，每张支票仅限入账一次）：

1. **通过银行菜单：** 输入 `/bank open` 打开面板，手持支票点击存入按钮。
2. **手持直接兑换：** 将支票拿在手上，点击鼠标右键。

若兑回过程发生异常：
- **存入被拒绝：** 物品无效、已被兑换或货币不存在时，支票会保留在背包内。请勿重复尝试，联系管理员确认。
- **扣除延迟或保留：** 若款项已入账但物品未能自动清除，服务器会记录交易 ID 与入账明细。请保留物品并联系管理员核对。

## 我想查看富豪排行榜

想知道谁最有钱，打：

```text
/baltop top [currency]
```

不填货币就用服务器设置的默认货币。想看特定货币这样打：

```text
/baltop top token
```

这个指令需要 `aceeconomy.command.baltop`，会列出所选货币的排名、玩家名称和余额。

## 我想使用银行面板

执行以下指令打开银行仪表板菜单：

```text
/bank open
```

此指令仅限玩家执行，需要 `aceeconomy.command.bank` 权限。若服务器在玩家打开界面期间重载了布局设置，菜单会自动依新布局重建并在原地重整。

- **Java 版客户端：** 呈现自定义箱子 GUI，提供账户信息、资产明细、历史记录及支票存提按钮。
- **基岩版客户端（Geyser + Floodgate）：** 呈现原生表单，显示余额并提供存入、提取与关闭选项。提取时需输入金额与币别，并经二次确认后才执行交易。
两种客户端共用同一套底层经济逻辑，具备完全相同的余额验证与防伪规则。

## 我想使用多种货币

想用默认货币之外的余额，就在指令后面加上货币 ID。所有标有 `[currency]` 的指令都接受服务器配置中的货币 ID。默认配置包含 `dollar` 和 `token`，服务器也可以另外定义更多货币。

平常的经济就省略货币 ID，活动的独立余额就把 ID 加上：

```text
/money balance <player> token
/pay send Alex 10 token
/withdraw cash 5 token
/baltop top token
```

找货币 ID 时大小写和前后空格不会对应到另一个货币，但金额仍要符合该货币设置的小数位数。`scale: 0` 的货币只能输入整数；`scale: 2` 的货币最多可输入两位小数。被提示金额无效就先看[常见输入问题](#常见输入问题)。

## 我想了解管理员造成的余额变化

服务器管理员可以发放、扣除或直接设置玩家余额。这些操作影响到你时，AceEconomy 可以显示包含金额和货币的玩家通知。想确认结果就查一次余额：

```text
/money balance
```

如果你预期会收到奖励或修正，却看不懂余额变化，请向服务器管理员确认交易背景。管理指令语法与权限请参考[指令与权限](commands.zh-CN.md)。

## 常见输入问题

### 指令提示金额无效

先确认三件事：输入的是有效数字、金额大于 0、小数位数没有超过该货币的设置。过大的金额也会被拒绝。如果货币使用 `scale: 2`，可以先用 `10` 或 `10.50` 这样的小额测试。

### 找不到货币

请输入服务器配置中的货币 ID，不要输入显示名称或符号。支持补全时，输入指令会出现货币建议；如果仍然被拒绝，请向管理员确认当前启用的货币。

### 找不到玩家

请检查拼写，并使用服务器能够识别的玩家名称。执行 `/pay send` 时，也请确认你是以玩家身份输入，而且不是付款给自己。

### 我没有权限

请服务器管理员确认该指令的权限：

| 指令 | 权限 |
| --- | --- |
| `/money` | `aceeconomy.command.money` |
| `/pay` | `aceeconomy.command.pay` |
| `/withdraw` | `aceeconomy.command.withdraw` |
| `/baltop` | `aceeconomy.command.baltop` |
| `/bank` | `aceeconomy.command.bank` |

### 银行支票没有出现在背包

先检查背包是否已满；没有空位时无法取得银行支票。如果指令显示经济系统错误，请先确认金额与可用余额，问题持续时再请管理员协助。
