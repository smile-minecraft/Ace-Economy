## 开始前

v2 指令会在主指令后接一个动作。例如查询余额要使用 `/money balance`，不要套用旧版的缩写写法。尖括号中的文字是預留位置，请把 `<player>`、`<amount>` 或 `<currency>` 换成实际内容，不要连尖括号一起输入。

省略 `[currency]` 时，AceEconomy 会使用服务器设置的默认货币。货币 ID 来自服务器配置，玩家看到的显示名称可能和 ID 不同；不确定时，请向管理员确认要输入哪个 ID。

## 我想查询余额

### 查询自己的余额

输入：

```text
/money balance
```

画面会显示你在默认货币中的余额。要查询指定货币，请在自己的玩家名称后面加上货币 ID：

```text
/money balance <player> <currency>
```

这个指令需要 `aceeconomy.command.money`。

### 查询其他玩家的余额

输入玩家名称；需要时再加上货币 ID：

```text
/money balance <player> [currency]
```

例如：

```text
/money balance Alex token
```

这个查询同样使用 `aceeconomy.command.money` 权限。

## 我想付款给其他玩家

输入：

```text
/pay send <player> <amount> [currency]
```

例如：

```text
/pay send Alex 250
```

这会使用默认货币向 `Alex` 转账 250。如果要使用其他货币，请明确填入货币 ID：

```text
/pay send Alex 10 token
```

`/pay` 只能由玩家执行，并需要 `aceeconomy.command.pay`。金额必须大于 0，且符合所选货币允许的小数位数。转账成功后，你会看到金额和收款人；收款玩家也会收到对应的入账通知。

## 我想把钱变成可以携带的物品

### 提取银行支票

输入：

```text
/withdraw cash <amount> [currency]
```

例如：

```text
/withdraw cash 100
```

AceEconomy 会从你的余额中扣除指定金额，并给你一张实体银行支票。提取前请先留出一个空背包格。这个指令只能由玩家执行，并需要 `aceeconomy.command.withdraw`。

### 兑换银行支票

使用 `/bank open` 打开银行面板，手持银行支票并点击存款按钮（上方中间的格子），金额就会存入你的账户，支票也会从手中消失。每张支票只能兑换一次，服务器会永久记住已经兑换过的支票。如果存款被拒绝（物品无效、已经使用过或货币未知），支票会留在你手上；请保留物品并找管理员处理，不要尝试复制交易。

目前还不支持“右键支票兑换”；银行面板的存款按钮是唯一的兑换方式。

## 我想查看富豪排行榜

输入：

```text
/baltop top [currency]
```

不填写货币时，排行榜会使用服务器设置的默认货币。要查看特定货币，可以这样输入：

```text
/baltop top token
```

这个指令需要 `aceeconomy.command.baltop`，并会列出所选货币的排名、玩家名称和余额。

## 我想使用银行面板

输入：

```text
/bank open
```

银行是玩家专用的界面，可以在同一个地方查看账户区域，并使用面板提供的银行支票提取功能。操作完成后即可关闭面板。这个指令需要 `aceeconomy.command.bank`。

## 我想使用多种货币

所有标有 `[currency]` 的指令都接受服务器配置中的货币 ID。默认配置包含 `dollar` 和 `token`，服务器也可以另外定义更多货币。

如果使用服务器的一般经济，就省略货币 ID；如果活动使用另一个独立余额，就把 ID 加上：

```text
/money balance <player> token
/pay send Alex 10 token
/withdraw cash 5 token
/baltop top token
```

查找货币 ID 时，大小写和前后空格不会产生另一个货币。不过金额仍需符合该货币设置的小数位数。`scale: 0` 的货币只能输入整数；`scale: 2` 的货币最多可输入两位小数。

## 我想了解管理员造成的余额变化

服务器管理员可以发放、扣除，或直接设置玩家余额。这些操作影响到你时，AceEconomy 可以显示包含金额和货币的玩家通知。你可以使用下面的指令确认结果：

```text
/money balance
```

如果你预期会收到奖励或修正，但看不懂余额变化，请向服务器管理员确认交易背景。管理指令语法与权限请参考[指令与权限](commands.zh-CN.md)。

## 常见输入问题

### 指令提示金额无效

请确认输入的是有效数字、大于 0，而且小数位数没有超过该货币的设置。过大的金额也会被拒绝。如果货币使用 `scale: 2`，可以先用 `10` 或 `10.50` 这样的较小金额测试。

### 找不到货币

请输入服务器配置中的货币 ID，不要输入显示名称或符号。支持补全时，输入指令会出现货币建议；如果仍然被拒绝，请向管理员确认当前启用的货币。

### 找不到玩家

请检查拼写，并使用服务器能够识别的玩家名称。执行 `/pay send` 时，也请确认你是以玩家身份输入，而且不是付款给自己。

### 我没有权限

请服务器管理员确认该指令的权限：

| 指令 | 权限 |
| --- | --- |
| `/money` | `aceeconomy.command.money` |
| `/pay` | `aceeconomy.command.pay` |
| `/withdraw` | `aceeconomy.command.withdraw` |
| `/baltop` | `aceeconomy.command.baltop` |
| `/bank` | `aceeconomy.command.bank` |

### 银行支票没有出现在背包

先检查背包是否已满；没有空位时无法取得银行支票。如果指令显示经济系统错误，请先确认金额与可用余额，问题持续时再请管理员协助。
