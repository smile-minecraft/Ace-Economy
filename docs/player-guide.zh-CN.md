## 开始前

先知道两件事。第一，v2 指令都是「主指令加动作」：查余额要打 `/money balance`，不要用旧版的缩写写法。第二，尖括号里的是预留位置，请把 `<player>`、`<amount>` 或 `<currency>` 换成实际内容，不要连尖括号一起输入。

想做的事很单纯就省略 `[currency]`，AceEconomy 会用服务器设置的默认货币。货币 ID 来自服务器配置，你看到的显示名称可能和 ID 不同；不确定要填哪个 ID，直接问管理员。

## 我想查询余额

### 查询自己的余额

想知道自己有多少钱，打：

```text
/money balance
```

画面会显示你在默认货币中的余额。想查指定货币，在自己的玩家名称后面加上货币 ID：

```text
/money balance <player> <currency>
```

这个指令需要 `aceeconomy.command.money`。没看到数字就先看[常见输入问题](#常见输入问题)，多半是货币 ID 或权限的问题。

### 查询其他玩家的余额

想看别人的余额，输入玩家名称，需要时再加上货币 ID：

```text
/money balance <player> [currency]
```

例如：

```text
/money balance Alex token
```

这个查询同样使用 `aceeconomy.command.money` 权限。

## 我想付款给其他玩家

想把钱转给别人，打：

```text
/pay send <player> <amount> [currency]
```

例如：

```text
/pay send Alex 250
```

这会用默认货币转 250 给 `Alex`。想用其他货币就明确填入货币 ID：

```text
/pay send Alex 10 token
```

`/pay` 只能由玩家执行，并需要 `aceeconomy.command.pay`。金额必须大于 0，也要符合所选货币允许的小数位数。转账成功后你会看到金额和收款人，对方也会收到入账通知。如果没转成，先看[常见输入问题](#常见输入问题)，再找管理员确认。

## 我想把钱变成可以携带的物品

### 提取银行支票

想把余额换成拿在手上的支票，打：

```text
/withdraw cash <amount> [currency]
```

例如：

```text
/withdraw cash 100
```

AceEconomy 会从你的余额中扣除指定金额，给你一张实体银行支票。动手前先留出一个空背包格。这个指令只能由玩家执行，并需要 `aceeconomy.command.withdraw`。支票没出现在背包里，先检查背包是不是满了，做法见[常见输入问题](#常见输入问题)。

### 兑换银行支票

想把支票换回余额有两种做法，效果完全一样。用 `/bank open` 打开银行面板，手持银行支票并点击存入按钮（上方中间的格子），金额就会存入你的账户，支票也会从手中消失；直接手持支票按右键也能兑换。两种方式走同一条不会重复入账的路径，每张支票只能兑换一次，服务器会永久记住已经兑换过的支票。

兑换失败也别慌，东西不会凭空消失：

- 存入被拒绝（物品无效、已经使用过或货币未知），支票会留在你手上。把物品收好并找管理员处理，不要尝试复制交易。
- 万一钱已经到账、支票却拿不掉，这笔钱照样算数：多张的整叠会留在手上，单张的不保证还在。把手上剩下的收好、不要再点一次，直接联系管理员。服务器记录里有支票编号、玩家和实际入账金额，管理员核对之后会帮你人工补上。

## 我想查看富豪排行榜

想知道谁最有钱，打：

```text
/baltop top [currency]
```

不填货币就用服务器设置的默认货币。想看特定货币这样打：

```text
/baltop top token
```

这个指令需要 `aceeconomy.command.baltop`，会列出所选货币的排名、玩家名称和余额。

## 我想使用银行面板

想在同一个地方看账户、存入支票或提取，打：

```text
/bank open
```

银行是玩家专用的界面，事情办完关闭就好。这个指令需要 `aceeconomy.command.bank`。

Java 玩家看到的是箱子菜单；基岩版玩家（Geyser + Floodgate）看到的是原生表单。表单会显示余额，并提供三个按钮：存入手持的支票、提取、关闭。提取会先要求输入金额与货币，再出现确认画面，确认之前不会有任何变动。关闭表单或输入无效的值都不会影响余额。两种界面走同一条存取款路径，所以一票一兑、背包满检查这些规则到处都一样。

## 我想使用多种货币

想用默认货币之外的余额，就在指令后面加上货币 ID。所有标有 `[currency]` 的指令都接受服务器配置中的货币 ID。默认配置包含 `dollar` 和 `token`，服务器也可以另外定义更多货币。

平常的经济就省略货币 ID，活动的独立余额就把 ID 加上：

```text
/money balance <player> token
/pay send Alex 10 token
/withdraw cash 5 token
/baltop top token
```

找货币 ID 时大小写和前后空格不会对应到另一个货币，但金额仍要符合该货币设置的小数位数。`scale: 0` 的货币只能输入整数；`scale: 2` 的货币最多可输入两位小数。被提示金额无效就先看[常见输入问题](#常见输入问题)。

## 我想了解管理员造成的余额变化

服务器管理员可以发放、扣除或直接设置玩家余额。这些操作影响到你时，AceEconomy 可以显示包含金额和货币的玩家通知。想确认结果就查一次余额：

```text
/money balance
```

如果你预期会收到奖励或修正，却看不懂余额变化，请向服务器管理员确认交易背景。管理指令语法与权限请参考[指令与权限](commands.zh-CN.md)。

## 常见输入问题

### 指令提示金额无效

先确认三件事：输入的是有效数字、金额大于 0、小数位数没有超过该货币的设置。过大的金额也会被拒绝。如果货币使用 `scale: 2`，可以先用 `10` 或 `10.50` 这样的小额测试。

### 找不到货币

请输入服务器配置中的货币 ID，不要输入显示名称或符号。支持补全时，输入指令会出现货币建议；如果仍然被拒绝，请向管理员确认当前启用的货币。

### 找不到玩家

请检查拼写，并使用服务器能够识别的玩家名称。执行 `/pay send` 时，也请确认你是以玩家身份输入，而且不是付款给自己。

### 我没有权限

请服务器管理员确认该指令的权限：

| 指令 | 权限 |
| --- | --- |
| `/money` | `aceeconomy.command.money` |
| `/pay` | `aceeconomy.command.pay` |
| `/withdraw` | `aceeconomy.command.withdraw` |
| `/baltop` | `aceeconomy.command.baltop` |
| `/bank` | `aceeconomy.command.bank` |

### 银行支票没有出现在背包

先检查背包是否已满；没有空位时无法取得银行支票。如果指令显示经济系统错误，请先确认金额与可用余额，问题持续时再请管理员协助。
